# Meeting AI — 회의 요약 앱

회의나 중요한 이야기를 **녹음**하고 **끝났어요**를 누르면, 핵심 주제 · 결정된 것 · 할 일 · 아직 못 정한 것을 정리해 주는 웹 앱이에요.
캐릭터(도토 · 몽글이 · 냥비서) 중 마음에 드는 화면을 골라 쓸 수 있어요.

| | [meeting_gemini](meeting_gemini/) | [meeting_openai](meeting_openai/) |
|---|---|---|
| AI | Google Gemini | OpenAI (gpt-4o-transcribe + gpt-5-mini) |
| 시작 비용 | **무료로 시작** (하루 한도 있음) | 크레딧 충전 필요 (최소 $5) |
| 1시간 회의 | 무료 한도 안에서 0원 | 약 $0.37 (약 500원) |
| 장점 | 카드 없이 바로 시작 | 서버가 안정적이고 남은 녹음 시간을 보여 줘요 |
| 주의 | 무료 플랜은 입력이 구글 제품 개선에 쓰일 수 있어요 | 크레딧은 1년 뒤 만료, 환불 불가 |

## 어떻게 쓰나요

1. 버전을 골라 폴더의 `README.md` 안내대로 **API 키**를 만들어 붙여넣어요. (키는 내 브라우저에만 저장돼요)
2. **녹음 시작** → 회의 → **끝났어요**.
3. 핵심 요약 카드가 나와요. 공유 · 복사 · 파일 저장으로 내보내고, 전체 기록은 파일로 백업해 두세요.

### 내 컴퓨터에서 열기

```bash
git clone https://github.com/kuventus14/meeting-ai.git
cd meeting-ai
python3 -m http.server 8000      # Windows: py -m http.server 8000
```

브라우저에서 `http://localhost:8000/` 를 열고 버전을 고르세요. 마이크는 `localhost` 또는 `https` 주소에서만 쓸 수 있어요.

## 개인정보

- **중간 서버가 없어요.** 녹음과 키는 내 브라우저에서 곧바로 Google 또는 OpenAI 로 가고, 이 저장소 주인은 아무것도 받지 않아요.
- 기록(요약, 받아쓴 글)은 **이 기기의 브라우저에만** 저장돼요. 녹음 원본은 정리가 끝나면 기본으로 지워요.
- 앱은 AI 서비스 외의 다른 곳으로 연결하지 않아요. (외부 글꼴·분석 도구 없음)
- 회의 녹음은 참석자에게 알리고 동의를 받는 게 좋아요. 대화 당사자가 아닌 녹음은 법에 어긋날 수 있어요.

## 한계 (솔직하게)

- 음성 인식은 **숫자 · 날짜 · 영어 이름 · 고유 명사를 틀릴 수 있어요.** 결과 화면에서 "숫자·날짜 확인"과 받아쓴 전체 글을 꼭 대조하세요.
- 소음 제거는 브라우저 기능에 의존해요. 겹쳐 말하는 소리나 아주 시끄러운 곳은 완전히 걸러지지 않아요.
- 폰 브라우저는 화면이 꺼지면 녹음이 멈출 수 있어요. 화면을 켜 두세요.
- 두 버전은 서로 다른 모델을 써서 결과가 달라요. 가능하면 같은 녹음으로 두 버전을 비교해 보세요.

## 폴더 구조

```
meeting-ai/
├─ index.html          버전 고르기 페이지
├─ meeting_gemini/     Gemini 판 (engine.js 만 다름)
├─ meeting_openai/     OpenAI 판
└─ scripts/check-sync.sh   두 폴더의 공통 파일이 같은지 확인
```

공통 파일(`app.js` `recorder.js` `storage.js` `summary.js` `styles.css` `characters.js`)은 두 폴더에 같은 내용이 들어 있어요.
고칠 때는 한쪽을 고친 뒤 다른 쪽에 복사하고 `scripts/check-sync.sh` 로 확인하세요.
