# 회의 요약 — OpenAI 판

회의를 녹음하고 **끝났어요**를 누르면 핵심 주제, 결정된 것, 할 일, 아직 못 정한 것을 정리해 주는 웹 앱이에요.
OpenAI 로 받아쓰기(`gpt-4o-transcribe`)와 요약(`gpt-5-mini`)을 하고, **남은 크레딧으로 몇 시간 더 녹음할 수 있는지** 보여 줘요.

> 무료로 시작하고 싶다면 [Gemini 판](../meeting_gemini/)을 쓰세요.

## 3분 설치

1. **앱 열기**
   - 웹 주소로 열 수 있다면 그 주소로 들어가요. (저장소 첫 화면의 README 참고)
   - 내 컴퓨터에서 열려면 저장소를 내려받은 뒤 터미널에서:
     ```bash
     cd meeting-ai
     python3 -m http.server 8000
     ```
     그다음 브라우저에서 `http://localhost:8000/meeting_openai/` 를 열어요. (Windows 는 `py -m http.server 8000`)
2. **화면 고르기** — 첫 화면에서 마음에 드는 캐릭터를 골라요. 나중에 설정에서 바꿀 수 있어요.
3. **OpenAI 키 만들기** (ChatGPT 구독과는 별개예요)
   1. [OpenAI 플랫폼](https://platform.openai.com/api-keys) 에 로그인해요.
   2. **Billing** 에서 카드를 등록하고 크레딧을 충전해요. 처음에는 **$5** 면 충분해요. **자동 충전(auto-recharge)은 꺼 두세요.**
   3. **API keys → Create new secret key** 로 키를 만들고 복사해요.
   4. 앱의 입력 칸에 붙여넣고 **연결 테스트하고 저장**을 눌러요.
4. **잔액 입력** — 홈 화면의 "잔액 입력"에 OpenAI 결제 페이지에서 본 남은 금액을 적어요. 그러면 남은 녹음 시간을 보여 줘요.
5. **녹음 시작** 을 누르고 마이크 사용을 허용해요.

## 비용

| | 가격 |
|---|---|
| 받아쓰기 (`gpt-4o-transcribe`) | 분당 약 $0.006 → **1시간 약 $0.36** |
| 요약 (`gpt-5-mini`) | 1시간 회의 기준 약 1센트 |
| **합계** | **1시간 회의 약 $0.37 (약 500원)** |

$5 를 충전하면 약 13시간 분량이에요. 가격은 OpenAI 가격 페이지 기준이며 바뀔 수 있어요.

- 충전한 크레딧은 **1년 뒤 사라지고**, 환불은 원칙적으로 안 돼요.
- 크레딧이 떨어지면 "크레딧이 부족해요"라고 알려 주고, 녹음은 지워지지 않아요. 충전한 뒤 이어서 정리하면 돼요.

### "남은 시간"은 추정이에요

OpenAI 는 API 키로 **잔액을 읽어 가도록 허용하지 않아요.** 그래서 이 앱은 이렇게 계산해요.

1. 사용자가 입력한 잔액에서
2. 앱이 사용한 만큼(받아쓰기 분당 단가 + 요약 토큰 단가)을 빼고
3. 남은 금액을 1시간당 비용으로 나눠서 남은 시간을 보여 줘요.

다른 곳(다른 앱, 다른 기기)에서 같은 키를 쓰면 어긋나요. 가끔 결제 페이지의 잔액으로 **다시 맞춰 주세요.** 정확한 잔액은 [결제 페이지](https://platform.openai.com/settings/organization/billing/overview)에서만 알 수 있어요.

## 알아두세요

- 음성 인식은 **숫자·날짜·영어 이름을 틀릴 수 있어요.** 결과 화면의 "숫자·날짜 확인"과 "받아쓴 전체 글"에서 꼭 대조하세요.
- 키와 기록은 **이 기기의 브라우저에만** 저장돼요. 공용 컴퓨터에서는 쓰지 마세요.
- 녹음은 10분마다 조각으로 자동 저장돼서, 탭이 갑자기 닫혀도 마지막 몇 초만 잃어요. 다시 열면 "복구하기"가 떠요.

## 소음이 있는 곳에서

- 마이크를 열 때 브라우저의 **소음 제거 · 에코 제거 · 자동 음량 조절**을 켜요. (설정에서 끌 수 있어요)
- 녹음 시작 후 몇 초 동안 말소리와 배경 소음의 차이를 재서, 환경이 나쁘면 화면에 알려 줘요.
- 겹쳐서 말하거나 아주 시끄러운 곳은 완전히 걸러지지 않아요. **마이크를 말하는 사람 가까이** 두는 게 가장 효과가 커요.

## 기록 저장과 백업

- 기록은 브라우저 안에 자동 저장돼요. 브라우저 데이터를 지우거나 시크릿 모드를 쓰면 사라져요.
- 결과 화면에서 **공유 · 복사 · 파일로 저장**을 할 수 있고, 기록 화면에서 **전체 백업**을 파일로 내려받을 수 있어요. (API 키와 녹음 원본은 백업에 들어가지 않아요)
- 크롬·엣지 데스크톱에서는 **자동 저장 폴더**를 정해 두면 정리가 끝날 때마다 `.md` 파일이 저장돼요.

## 어떻게 동작하나요

```
마이크 → (10분마다 조각 저장) → gpt-4o-transcribe 받아쓰기 → gpt-5-mini 요약 → 결과 카드
```

- 중간 서버가 없어요. 브라우저가 OpenAI API 로 **직접** 보내요.
- 모델 이름과 가격은 [`engine.js`](engine.js) 맨 위에서 바꿀 수 있어요.
