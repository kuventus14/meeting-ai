# 회의 요약 — Gemini 판

회의를 녹음하고 **끝났어요**를 누르면 핵심 주제, 결정된 것, 할 일, 아직 못 정한 것을 정리해 주는 웹 앱이에요.
구글 Gemini 로 받아쓰기와 요약을 하고, **무료로 시작**할 수 있어요.

> 더 정확한 받아쓰기가 필요하거나 무료 한도가 부족하면 [OpenAI 판](../meeting_openai/)을 쓰세요.

## 3분 설치

1. **앱 열기**
   - 웹 주소로 열 수 있다면 그 주소로 들어가요. (저장소 첫 화면의 README 참고)
   - 내 컴퓨터에서 열려면 저장소를 내려받은 뒤 터미널에서:
     ```bash
     cd meeting-ai
     python3 -m http.server 8000
     ```
     그다음 브라우저에서 `http://localhost:8000/meeting_gemini/` 를 열어요. (Windows 는 `py -m http.server 8000`)
2. **화면 고르기** — 첫 화면에서 마음에 드는 캐릭터를 골라요. 나중에 설정에서 바꿀 수 있어요.
3. **Gemini 키 만들기**
   1. [Google AI Studio](https://aistudio.google.com/apikey) 에 구글 계정으로 로그인해요.
   2. **Create API key** 를 눌러 키를 만들고 복사해요.
   3. 앱의 입력 칸에 붙여넣고 **연결 테스트하고 저장**을 눌러요.
4. **녹음 시작** 을 누르고 마이크 사용을 허용해요.

## 알아두세요

- **무료 플랜은 입력한 내용이 구글 제품 개선에 쓰일 수 있어요.** 민감한 회의는 결제를 연결한 유료 키를 쓰거나, 연습용 내용으로만 해 보세요.
- 무료 사용량에는 하루 한도가 있고 서버가 혼잡할 때가 있어요. 앱이 알아서 다른 모델로 바꿔 가며 시도하고, 그래도 안 되면 "다시 시도"를 보여 줘요. 녹음은 지워지지 않아요.
- 음성 인식은 **숫자·날짜·영어 이름을 틀릴 수 있어요.** 결과 화면의 "숫자·날짜 확인"과 "받아쓴 전체 글"에서 꼭 대조하세요.
- 키와 기록은 **이 기기의 브라우저에만** 저장돼요. 공용 컴퓨터에서는 쓰지 마세요.

## 소음이 있는 곳에서

- 마이크를 열 때 브라우저의 **소음 제거 · 에코 제거 · 자동 음량 조절**을 켜요. (설정에서 끌 수 있어요)
- 녹음 시작 후 몇 초 동안 말소리와 배경 소음의 차이를 재서, 환경이 나쁘면 화면에 알려 줘요.
- 겹쳐서 말하거나 아주 시끄러운 곳은 완전히 걸러지지 않아요. **마이크를 말하는 사람 가까이** 두는 게 가장 효과가 커요.

## 기록 저장과 백업

- 기록은 브라우저 안에 자동 저장돼요. 브라우저 데이터를 지우거나 시크릿 모드를 쓰면 사라져요.
- 결과 화면에서 **공유 · 복사 · 파일로 저장**을 할 수 있고, 기록 화면에서 **전체 백업**을 파일로 내려받을 수 있어요. (API 키와 녹음 원본은 백업에 들어가지 않아요)
- 크롬·엣지 데스크톱에서는 **자동 저장 폴더**를 정해 두면 정리가 끝날 때마다 `.md` 파일이 저장돼요.

## 어떻게 동작하나요

```
마이크 → (30분마다 조각 저장) → Gemini 받아쓰기 → Gemini 요약 → 결과 카드
```

- 중간 서버가 없어요. 브라우저가 구글 API 로 **직접** 보내요.
- 받아쓰기 모델 순서: `gemini-3.5-transcribe` → `gemini-3.8-flash` → `gemini-3.6-flash` → `gemini-3.5-flash-lite`
- 요약 모델 순서: `gemini-3.8-flash` → `gemini-3.6-flash` → `gemini-3.5-flash` → `gemini-3.5-flash-lite` → `gemini-flash-latest`
- 모델 이름은 [`engine.js`](engine.js) 맨 위에서 바꿀 수 있어요.
